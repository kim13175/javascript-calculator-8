# javascript-calculator-precourse

## 🛠️ 기능 구현

- [x] 문자열을 입력받고 결과를 출력한다.
- [x] 커스텀 문자가 있을 경우 커스텀 문자를 체크한다.
- [x] 구분자를 담는 배열을 만들고 커스텀 문자가 있을 경우 배열에 추가한다.
- [x] 커스텀 구분자를 추출하는 로직을 파싱 메서드 안에 담는다. 
- [x] 커스텀 문자나 기본문자를 기준으로 숫자를 나누고 더한 결과를 출력한다.

## 🤔 예외 상황

- [x] 음수를 문자열로 받을 경우
- [x] 커스텀 문자와 기본 문자가 아닌 다른 문자일 경우
- [ ] 문자열의 마지막이 특수 문자일 경우
